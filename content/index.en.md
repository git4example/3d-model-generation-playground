In this workshop you will learn how to generate 3D models from 2D images or from text-to-2D-to-3D using Generative AI and NVIDIA GPUs on AWS, using an open source Foundation Models, deploy and scale image-to-3D model inference using AWS compute services to build a scalable architecture for 3D asset generation and management with the following AWS services stack:

* Amazon Elastic Kubernetes Service (EKS) - Orchestration layer
* Amazon S3 - Asset storage and management
* Amazon CloudFront - Frontend hosting and deployment
* Amazon Bedrock - Image generation

You will get hands-on experience configuring and deploying components for 3D model generation by using image diffusion models, setting up 3D generation models on EKS, and loading the result. You will learn how to scale this pattern for enterprise-level 3D asset creation and management. You will also conduct tests across multiple models to see the model quality.
